# Короткий адрес сайта: что можно сделать

Сейчас: `https://hazzy3525-create.github.io/seversvet/` — длинно и в поиске слабее собственного домена.

## Вариант 1. Бесплатно и сегодня — `seversvet.github.io`

Логин `seversvet` на GitHub **свободен** (проверено 02.08.2026).

1. Зарегистрировать аккаунт GitHub с логином `seversvet`.
2. Создать в нём репозиторий с именем ровно `seversvet.github.io`.
3. Скопировать туда содержимое папки `site/` (или добавить второй remote и запушить).
4. В настройках репозитория → Pages → Source: ветка `main`, папка `/ (root)`.
5. Перебить адрес в файлах одной командой и запушить:

```bash
node tools/set-domain.js https://seversvet.github.io/ ; node tools/build-offers.js
```

Итог: `https://seversvet.github.io` — вдвое короче, читается как бренд. Стоит 0 ₽.

## Вариант 2. Свой домен — правильный для поиска

`seversvet.ru` **занят** (стоит на хостинге Timeweb — возможно, продаётся).
Свободны на 02.08.2026 (по DNS; подтвердить у регистратора при покупке):
`seversvet.pro`, `seversvet.studio`, `seversvet.rent`, `seversvet.site`, `seversvet.tech`, `severs-vet.ru`.

Цена: 200–2 500 ₽/год в зависимости от зоны (`.ru` дешевле всего, `.studio`/`.rent` дороже).
Регистраторы: reg.ru, timeweb, nic.ru.

После покупки:

1. В DNS домена прописать записи для GitHub Pages:

```
A     @    185.199.108.153
A     @    185.199.109.153
A     @    185.199.110.153
A     @    185.199.111.153
CNAME www  hazzy3525-create.github.io.
```

2. Дождаться, пока записи разойдутся (10–60 минут), и выполнить **из папки сайта**:

```bash
cd C:\src\seversvet\site ; node tools/set-domain.js https://seversvet.pro/ --cname seversvet.pro
```

Скрипт сам пересоберёт разметку каталога и проверит DNS: если домен ещё не смотрит на GitHub,
файл CNAME он не создаст и объяснит, чего не хватает. Это защита — CNAME с ненастроенным доменом
кладёт сайт по обоим адресам сразу.

3. Запушить, затем в GitHub → Settings → Pages → Custom domain вписать домен и включить **Enforce HTTPS**
   (сертификат выпускается автоматически за 10–60 минут).

4. Старый адрес продолжит работать и будет отдавать редирект — накопленные ссылки не потеряются.

## Чего делать не надо

Сокращатели ссылок (clck.ru, vk.cc) выглядят короче, но для поиска бесполезны: индексируется всё равно
конечный адрес, а превью в мессенджерах иногда ломается. Домен решает обе задачи сразу.
